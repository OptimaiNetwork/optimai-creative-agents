# Benchmarks

Serve the package folder (`python3 -m http.server --bind 127.0.0.1` from the package root) and open `examples/benchmark/`. Pick an image size and press **Run benchmarks**: each operation is timed on this device and the table can be copied as Markdown. See [docs/benchmarks.md](../../docs/benchmarks.md) for how to read it and a published run.
