# Code of Conduct

OptimAI Creative Agents welcomes contributors with different backgrounds, experience levels and creative interests. Everyone participating in this repository's issues, pull requests and reviews is expected to help keep those spaces respectful and useful.

## Expected behavior

- Discuss ideas and implementation choices with patience and specific, constructive feedback.
- Respect differences in experience, identity and opinion. Accept corrections and take responsibility for mistakes.
- Keep discussions relevant to the project and respect others' time and contribution rights.
- Protect personal information, private creative work and credentials.

Harassment, discriminatory language, threats, sexualized attention, personal attacks, deliberate disruption and publishing another person's private information are unacceptable.

## Reporting and moderation

For an incident visible in an issue or pull request, ask a repository maintainer to review the affected discussion. Link the relevant content without repeating abusive material or disclosing personal information. If a maintainer provides a private contact route on GitHub, use it for sensitive reports. A confidential reporting channel is not established by this document; do not post sensitive details while requesting one.

Maintainers may edit or remove content, close discussions, restrict participation or block contributors when necessary to protect the community. They should consider the context and impact of the behavior, explain moderation decisions when appropriate and avoid exposing sensitive report details. Repeated or serious violations may result in a permanent restriction.

This policy applies in repository spaces and when someone represents this project in an official capacity. It does not authorize monitoring unrelated private activity. Security vulnerabilities follow the separate process in [SECURITY.md](./SECURITY.md).
